# 🌍 TourMate

TourMate is a smart tourism assistance mobile application developed using **Flutter**, **Django**, and **PostgreSQL**. The application helps tourists explore nearby attractions, navigate using Google Maps, receive emergency assistance, and access useful travel features.

---

## ✨ Features

- 🔐 User Registration & Login
- 📍 Nearby Tourist Places
- 🗺️ Google Maps Navigation
- 🏥 Nearby Hospitals
- 👮 Nearby Police Stations
- 🍽️ Nearby Restaurants
- 🌤️ Weather Information
- 🌐 Language Translator
- 📸 Photo Diary
- 🆘 Emergency SOS

## 🚀 Installation

### Clone Repository

```bash
git clone https://github.com/YOUR_USERNAME/tourmate_backend.git
```

### Create Virtual Environment

```bash
python -m venv env
```

### Activate Virtual Environment

Windows

```bash
env\Scripts\activate
```

Linux / Mac

```bash
source env/bin/activate
```

### Install Dependencies

```bash
pip install -r requirements.txt
```

### Run Migrations

```bash
python manage.py migrate
```

### Run Server

```bash
python manage.py runserver
```

Backend URL

```
http://127.0.0.1:8000/
```
